Encanto Decorações

Política de Privacidade

Última atualização: 25 de agosto de 2026

O Encanto Decorações é um sistema de gestão interno para operações de decoração de eventos. Esta página explica como tratamos os dados ao oferecer a integração opcional com o Google Agenda (Google Calendar). Nesta demonstração de portfólio, a integração real está desativada; o texto abaixo descreve o funcionamento do sistema original.

1. Dados acessados

Quando um usuário conecta sua conta Google pela tela de Agenda do sistema, solicitamos permissão para criar, atualizar e excluir eventos no Google Agenda do próprio usuário. Os dados enviados ao Google correspondem às informações do evento já cadastradas no sistema, como título, data, horário e local.

2. Finalidade do uso

Os dados são usados exclusivamente para manter os eventos cadastrados no Encanto Decorações sincronizados com o Google Agenda do usuário que autorizou a conexão. Não usamos esses dados para nenhuma outra finalidade.

3. Compartilhamento com terceiros

Não compartilhamos, vendemos ou divulgamos os dados da sua agenda a terceiros. As únicas partes envolvidas são o próprio usuário, o sistema Encanto Decorações e a API do Google Calendar, estritamente para viabilizar a sincronização solicitada.

4. Armazenamento

Os tokens de autorização do Google (necessários para manter a sincronização ativa) ficam armazenados de forma segura no banco de dados do sistema, associados à conta do usuário que realizou a conexão.

5. Revogação de acesso

O usuário pode desconectar a integração a qualquer momento pelo botão "Desconectar" na tela de Agenda do sistema, ou revogando o acesso diretamente pela página de permissões da sua conta Google.
