Política de Privacidade

Última atualização: 21 de setembro de 2026

O Estoque Aberto trata dados pessoais em conformidade com a Lei Geral de Proteção de Dados (Lei nº 13.709/2018, LGPD). Esta página é uma versão de demonstração de portfólio; os dados de contato abaixo são fictícios.

Dados que coletamos

  • Dados da empresa e dos gestores (nome, e-mail, telefone).
  • Dados das lojas (nome, código de acesso).
  • Dados de lançamentos (item, quantidade, laboratório, observações).
  • Em encomendas: nome e telefone do cliente da loja.

Por que coletamos

Os dados de encomenda (nome e telefone do cliente) existem apenas para que a loja consiga entrar em contato quando o produto chegar. Não usamos esses dados para marketing.

Por quanto tempo guardamos

O nome e telefone do cliente de uma encomenda são removidos automaticamente (anonimizados) do nosso banco de dados 2 meses após o registro, mantendo apenas o histórico do item.

Segurança

Senhas e códigos de acesso são armazenados com hash, nunca em texto puro. O acesso aos dados de cada empresa é isolado dos dados de outras empresas.

Seus direitos

Dúvidas sobre esta política podem ser enviadas para o gestor responsável pela sua empresa, ou para contato@estoqueaberto.exemplo.com.
